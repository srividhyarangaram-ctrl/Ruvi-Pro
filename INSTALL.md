# Ruvi Android installation

1. Deploy the contents of the `ruvi` folder to an HTTPS static host such as GitHub Pages or Netlify. Do not publish private OAuth credentials.
2. On your OnePlus phone open the HTTPS URL in Chrome.
3. Tap Chrome menu (three dots) > Install app (or Add to Home screen). Confirm.
4. Tap the Ruvi icon on your home screen.

## Subscription controls
Continue: marks a subscription to keep.
Discontinue: optionally open a provider HTTPS cancellation page and mark cancellation as pending. It DOES NOT cancel billing.
Confirm cancelled: use only after the provider confirms cancellation. Cancelled subscriptions are excluded from spending totals.

Gmail discovery requires Google Cloud OAuth configuration; this build has not been tested with a live Gmail account. Your records are kept in browser local storage, so back them up before clearing site data or changing phones.
